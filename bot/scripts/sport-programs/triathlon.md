# Анализ потребностей — Триатлон (Triathlon)

> Файл анализа (основа). Программа — в БД (шаблон `Triathlon — силовая база`).
> Упражнения ВАРЬИРУЕМЫ. Builder: `bot/scripts/sport-programs/triathlon.ts`.

## Уровень 1 — Анализ потребностей

### Регионы и приоритет
- **Плечо/манжета (ВЧ)**: ротаторы, задняя дельта, широчайшие — здоровье плеча для плавания + осанка при езде.
- **Нижняя цепь**: задняя цепь, квадрицепс, икра, glute med — бег + велосипед.
- **Кор**: стабильность таза, антиротация, туловище при всех трёх дисциплинах.
- **Одноопорная сила**: бег и велик — односторонние нагрузки.

### Ключевые задачи
1. **Здоровье плеча** (приоритет плавания): манжета, задняя дельта, контроль объёма (не перегружать на фоне объёмного плавания).
2. **Тяга/широчайшие**: осанка при езде на велике (против сутулости).
3. **Нижняя цепь**: задняя цепь + квад (педалирование/отталкивание).
4. **Перенос силы → плиометрика** (Фаза 3+).
5. **Аэроб**: велик/бег/плавание вне шаблона (кардио-поля в Дне C).

### Прекауции
- Не дублировать большой объём плеча с плаванием — умеренные подходы на манжету.
- Плиометрика — только с недели 9, после разминки.

## Уровень 2 — Макро-блоки и периодизация

### Порядок блоков
1. Разминка / мобильность плеча и ТБС.
2. Основной силовой блок по дню.
3. Односторонняя устойчивость.
4. Кор + манжета/задняя дельта.
5. Плиометрика (Фаза 3+) / кардио (велик/бег).
6. Заминка.

### Периодизация (12 недель, 3 дня)
- **1–2 Фундамент**: техника, лёгкая гипертрофия.
- **3–4 Гипертрофия**.
- **5–8 Сила** (%ПМ растёт).
- **9–11 Мощь + ВИИТ + плио**.
- **12 Делoad**.

### Формат дней (финал)
- **День 1 — Full Body (низ+верх)**: ЗС/квад + тяга/жим (ВП/ГП/ГЖ/ВЖ). Взрывная (Боковые запрыгивания, Фаза 3+) — строго в начале.
- **День 2 — Full Body (низ+верх)**: одностороннее + тяга/жим/ротаторы (ВП/ГП/ГЖ). Взрывная (Ротационный бросок медбола, Фаза 3+) — строго в начале.
- **День 3 — Кондиция + Кор (ОФП)**: сани/фермерская/слэм/бёрпи + кор. Без беговой/велик/плавательной нагрузки (клиент с другими тренерами).

> Взрывная/плиометрика — только в начале дня (после разминки), только Фаза 3+ (нед 9–11). Делoad — без неё.

## Уровень 3 — Пример наполнения (ВАРЬИРУЕМЫ)

### День 1 — Full Body (низ+верх)
- Боковые запрыгивания/приземления (латеральная плио, Фаза 3+) — строго в начале.
- Румянская тяга с гантелями (ЗЦ), Приседания со штангой (квад), Подъём на носки (икры).
- Тяга верхнего блока (ВП), Тяга к лицу (ГП), Жим гантелей на наклонной (ГЖ), Жим гантелей стоя (ВЖ).
- Паллоф-пресс (кор).

### День 2 — Full Body (низ+верх)
- Ротационный бросок медбола (ротационная мощь, Фаза 3+) — строго в начале.
- Болгарские выпады, Степ-ап с гантелями, Ракушка (glute med).
- Односторонняя румянская тяга (ЗЦ одной ногой).
- Подтягивания (ВП), Тяга гантели в наклоне (ГП), Отжимания (ГЖ), Отведение плеча наружу (манжета), Молотки (предплечье).
- Dead bug (кор).

### День 3 — Кондиция + Кор (ОФП)
- Боковые запрыгивания/приземления (плио, Фаза 3+) — строго в начале.
- Трастеры + Махи гирей + Фермерская прогулка (ОФП-кондиция).
- Медбол-слэм + Бёрпи.
- Планка + Боковая планка + Русский твист.
- Нордические наклоны (бицепс бедра) — эксцентрика 3-4 с.
- Велик/бег/плавание — вне шаблона (клиент с другими тренерами).
