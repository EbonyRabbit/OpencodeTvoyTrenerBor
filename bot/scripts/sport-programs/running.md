# Анализ потребностей - Бег (Running)

> Файл анализа (основа). Сама программа - в БД (шаблон `Running - силовая база`).
> Конкретные упражнения ВАРЬИРУЕМЫ. Builder: `bot/scripts/sport-programs/running.ts`.

## Уровень 1 - Анализ потребностей

### Регионы тела и приоритет
- **Нижняя часть (НЧ)**: задняя цепь (ягодичные, бицепс бедра), квадрицепс, икра (икроножная/камбаловидная), передняя большеберцовая, glute med/min, голеностоп.
- **Кор (К)**: стабильность поясницы, антиротация, контроль таза при односторонней опоре.
- **Верх (ВЧ, вторично)**: против округлых плеч (беговая осанка) - задняя дельта, ромбовидные; лёгкая сила для рук (махи).
- **Дыхание/аэроб**: общая выносливость через беговые сессии вне шаблона + кардио в Дне C.

### Ключевые задачи
1. **Профилактика травм** (приоритет): шина (передняя большеберцовая), колено бегуна (квад/glute med), ахилл/икра, плантарная фасция (голеностоп/интринсики).
2. **Односторонняя сила** - бег = одноопорное движение (выпады, RDL одной ногой, степ-ап).
3. **Задняя цепь** - бицепс бедра/ягодицы для отталкивания (Нордические наклоны, Румынская тяга).
4. **Беговая экономичность** - плиометрика (запрыгивания, боковые прыжки) строго после базы.
5. **Кор + осанка** - стабильность таза, против сутулости.

### Важно
- Плиометрика - только с недели 9, после разминки, мягкое приземление (без вальгуса).
- Передняя большеберцовая - без веса, высокие повторы.
- При боли в колене/ахилле - снизить объём одностороннего и плио.

## Уровень 2 - Макро-блоки и периодизация

### Порядок блоков (в тренировке)
1. Разминка / мобильность / активация glute med + голеностоп.
2. Основной силовой блок (задняя/передняя цепь по дню).
3. Односторонняя устойчивость (RDL одной ногой, выпады, степ-ап).
4. Кор + осанка (планка, твист, bird-dog, задняя дельта).
5. Плиометрика (Фаза 3+) / аэроб (бег) в Дне C.
6. Заминка / растяжка икр и бедра.

### Периодизация (12 недель, 3 дня/нед)
- **1-2 Фундамент**: техника, лёгкая гипертрофия, активация, базовый бег Z2.
- **3-4 Гипертрофия**: рост объёма по приоритетным мышцам.
- **5-8 Сила**: %ПМ растёт, объём чуть ниже.
- **9-11 Мощь + ВИИТ**: плиометрика, интервальный бег (400 м повторы), сила макс.
- **12 Разгрузка**: снижение объема/интенсивности, легкий бег.

### Распределение объёма (подходы/неделя)
- Ягодичные: 9-11
- Бицепс бедра (ЗЦ): 8-10
- Квадрицепс: 8-10
- Glute med/min: 6-8
- Икра: 4-6
- Передняя большеберцовая: 4-6
- Кор: 8-10
- Верх (осанка): 4-6

### Формат дней (финал)
- **День 1 - Full Body (низ+верх)**: ЗС/ягод + тяга/жим (ВП/ГП/ГЖ/ВЖ). Взрывная (Барьерные выпрыгивания, Фаза 3+) - строго в начале.
- **День 2 - Full Body (низ+верх)**: квад/привод + тяга/жим/ротаторы (ВП/ГП/ГЖ). Взрывная (Боковые запрыгивания, Фаза 3+) - строго в начале.
- **День 3 - Кондиция + Кор (ОФП)**: сани/фермерская/слэм/бёрпи + кор. Без беговой нагрузки (клиент бегает с другим тренером).

> Взрывная/плиометрика - только в начале дня (после разминки), только Фаза 3+ (нед 9-11). Разгрузка - без нее.

## Уровень 3 - Пример наполнения (ВАРЬИРУЕМЫ)

### День 1 - Full Body (низ+верх)
- Барьерные выпрыгивания (плио, Фаза 3+) - строго в начале.
- Румынская тяга с гантелями (ЗЦ) - `%ПМ`.
- Ягодичный мост (ягод) - гипертрофия.
- Подъем на носки (икры) - икры/ахилл, полная амплитуда 2с эксцентрика ниже опоры; прямое колено - икроножная, согнутое - камбаловидная.
- Тяга верхнего блока (ВП), Тяга к лицу (ГП), Жим гантелей на наклонной (ГЖ), Жим гантелей стоя (ВЖ).
- Паллоф-пресс (кор антиротация).

### День 2 - Full Body (низ+верх)
- Боковые запрыгивания/приземления (латеральная плио, Фаза 3+) - строго в начале.
- Приседания со штангой (квад), Болгарские выпады, Степ-ап с гантелями.
- Ракушка (glute med), Подъём носка на себя (передняя большеберцовая).
- Односторонняя румынская тяга (ЗЦ одной ногой) - контроль таза.
- Подтягивания (ВП), Тяга гантели в наклоне (ГП), Отжимания на брусьях (грудные/трицепс).
- Dead bug (кор).

### День 3 - Кондиция + Кор (ОФП)
- Барьерные выпрыгивания (плио, Фаза 3+) - строго в начале.
- Трастеры + Махи гирей + Фермерская прогулка (ОФП-кондиция).
- Медбол-слэм + Бёрпи.
- Планка + Планка Копенгагена + Русский твист.
- Нордические наклоны (бицепс бедра) - эксцентрика 3-4 с.
- Бег вне шаблона (клиент с другим тренером).
